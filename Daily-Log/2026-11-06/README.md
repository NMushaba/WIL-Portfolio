# Day 22 — 6 November 2026
## Updating the Zonke Revamp interface and visual design

My team was assigned to update the Zonke website’s user interface and visual design. I replaced existing website images with new images, changed the colour scheme, and updated page text as part of the visual refresh. These changes updated the appearance of the pages while retaining the marketplace’s purpose.

The project source uses Laravel and PHP, Blade templates, HTML, CSS, and JavaScript. The supplied local setup guide specifies XAMPP and MySQL/phpMyAdmin for running the application.

## Tools and technologies

- Laravel and PHP
- Blade templates
- HTML, CSS, and JavaScript
- XAMPP and MySQL/phpMyAdmin (specified in the project setup guide)

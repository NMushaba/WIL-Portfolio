# Day 6 — 28 August 2026
## Developing JavaScript functionality for the Coxy Wallet AI Music Contest

My team was assigned to develop an AI Music Contest add-on for Coxy Wallet, and I worked on its JavaScript component. The contest concept allows participants to connect a Cardano wallet, pay a 10 ADA entry fee, submit an AI-generated song, and let users listen to and vote for entries.

I worked on client-side JavaScript for the contest’s interactive features, including wallet connection, entry payment, song submission, displaying music entries, voting, the countdown, and user-facing messages. This work applied my web programming skills to a feature connected to a blockchain wallet.

## Tools and technologies

- JavaScript
- HTML
- Cardano wallet integration

# Day 1 — 3 August 2026
## Ubuntu installation and Linux command practice

After the company introductions, I was tasked with installing Ubuntu Linux on a PC because Tobb Technologies uses Linux in its work environment. I prepared a bootable USB drive, started the computer from the USB, followed the installation steps and checked that Ubuntu started successfully.

After installation, I used Ubuntu Terminal to practise file and directory management. I navigated between directories, created directories and files, and added content to files. This gave me practical experience installing an operating system and managing its file system through command-line instructions.

## Tools used

- Ubuntu Linux
- Bootable USB drive
- Ubuntu Terminal

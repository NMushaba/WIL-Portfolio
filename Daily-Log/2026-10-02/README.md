# Day 17 — 2 October 2026
## Defining Zonke’s visual system

I documented a proposed visual system for the Zonke marketplace. I specified a blue-focused colour direction and described how the colours could be applied across navigation, buttons, backgrounds, cards, borders, and error and success indicators.

I also documented the typography direction, including serif fonts, font weights, a base font size, and a heading hierarchy. These specifications provide consistent visual guidance and help users recognise and scan the interface content.

# Day 16 — 28 September 2026
## Receiving the initial Zonke UI/UX assignment

I was assigned to the UI/UX design workstream for the initial Zonke project as part of a two-person group. The task was to plan how the freelance marketplace could look and how users would move through it, using requirements supplied by another group.

My design contribution covered planning wireframes and Figma designs, arranging screen layouts, and considering navigation, forms, buttons, interactions, responsive layouts, and a clickable prototype. This work introduced me to translating system requirements into interface and navigation plans for the needs of clients and freelancers.

## Tools and technologies

- Figma
- UI/UX design
- Wireframing and prototyping

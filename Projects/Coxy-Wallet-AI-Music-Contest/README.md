# Coxy Wallet AI Music Contest

## Project overview

The AI Music Contest was designed as an add-on for Coxy Wallet. It allows participants to connect a Cardano wallet, pay a 10 ADA entry fee, submit an AI-generated song, and lets users listen to and vote for entries.

## My contribution

I worked on the client-side JavaScript for the contest’s interactive features. My work included wallet connection, entry payment, song submission, displaying music entries, voting, the countdown, and user-facing messages.

## Technologies

- JavaScript
- HTML
- CSS
- Cardano wallet integration

## Result

I contributed the JavaScript functionality for the contest interface and worked on responsive design so the page could adapt to different screen sizes.

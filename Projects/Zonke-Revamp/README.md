# Zonke Revamp — UI and Visual Updates

## Project overview

The Zonke Revamp updated the user interface and visual design of the freelance marketplace website.

## My contribution

My team was assigned to the UI and design work. I replaced existing website images with new images, changed the website’s colour scheme, and updated page text as part of the visual refresh.

## Technologies

- Laravel
- PHP
- Blade templates
- HTML
- CSS
- JavaScript

The project setup guide specifies XAMPP and MySQL/phpMyAdmin for running the application.

I contributed visual updates to the website by changing images, colours, and text. The screenshots below show the updated website.

# AI Donation Tracker

## Project overview

The AI Donation Tracker was planned as an application combining donation tracking, AI support, and Cardano blockchain functionality to address a real-world problem.

## My contribution

I contributed to selecting the project concept and implemented browser-side JavaScript features in `app.js`. I set up configuration and helper functions, displayed donation records and totals, handled rand donations and AI questions, connected Cardano wallets for ADA donations, and added transaction verification.

## Technologies

- JavaScript
- HTTP requests and JSON
- Cardano wallet integration
- HTML forms

## Result

I contributed interface functionality for recording and displaying donations, submitting questions to the AI feature, connecting a wallet, making ADA donations, and checking transaction status.

# Zonke Marketplace UI/UX Design

## Project overview

Zonke is a freelance marketplace concept connecting clients with freelancers. The UI/UX work focused on defining how users could navigate the marketplace and complete tasks such as posting a job, finding work, and viewing profiles.

## My contribution

I contributed to the UI/UX design workstream. I documented a proposed visual system, including colours and typography, and specified navigation and common interface elements such as buttons, profile cards, and forms.

I also documented user workflows, gaps in the proposed screens, and prototype requirements for responsive layouts, accessibility, and interface states such as loading, empty, error, and success.

## Tools and technologies

- Markdown
- UI/UX design documentation
- Figma and prototyping concepts
- Responsive design and accessibility guidelines

## Result

I produced design documentation covering the marketplace’s visual direction, navigation, interface components, user workflows, and prototype requirements.

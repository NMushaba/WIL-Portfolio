# Tobb Technologies Service Catalogue

## Project overview

The service catalogue was developed as a practical way to help Tobb Technologies present its services, reach prospective customers, and encourage enquiries about IT needs.

## My contribution

I reviewed the company’s services and value to prospective customers, then developed a service-catalogue concept and proposal. I organized the catalogue around hardware, networking, and software services, presenting them in relation to customer needs.

## Tools and technologies

- Markdown
- Visual design
- Service and customer research

## Result

I prepared a proposal and a customer-facing catalogue concept that can be adapted for digital or printed use.
